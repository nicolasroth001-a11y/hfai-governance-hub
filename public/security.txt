# HFAI Responsible Disclosure
#
# We welcome reports of security vulnerabilities. Please email
# security@hfa-i.org with:
#   - A clear description of the issue
#   - Steps to reproduce
#   - Your contact info for follow-up
#
# We commit to:
#   - Acknowledging receipt within 48 hours
#   - Providing a remediation timeline within 5 business days
#   - Crediting researchers (with permission) on our Trust Center
#

#   - Publicly disclose before we've had a chance to remediate
#   - Run automated scans that degrade service
